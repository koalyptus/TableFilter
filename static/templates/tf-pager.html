Web components pager demo

This page wires the Paging feature to the <tf-pager> custom element (#926) instead of the legacy spans and select. The element is not part of either published bundle, so the page imports it from source and initialises the feature once that registration settles. The bridge uses it only when it is registered before tf.init() runs, and only when enable_icons is off and no btn_*_page_html is configured (src/modules/paging.js, TODO #965). Open the page and page through the records: the buttons, the selector and the page attribute all drive the same page state, which the feature keeps.
