Vite UMD bundle demo

This page loads the Vite UMD build (dist/tablefilter/tablefilter.vite.js) instead of the webpack bundle used by the other demos, so the Vite-specific path (extension shims, flat window.TableFilter global and globalThis handling) is exercised by the accessibility specs and by manual review. npm run build:vite produces the bundle before the demos run.
