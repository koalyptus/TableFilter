Web components pop-up filters demo

Pop-up filters rendered through the <tf-popup-filter> custom element. Each header trigger is a button that opens the column filter in a popup with focus management, Escape and outside-pointer dismissal. Sortable headers are rendered through <tf-sort-header>, so each header can contain both the pop-up filter trigger and the sort trigger.

The configuration matches the legacy pop-up filters demo: col_1 is a select, col_2 a checklist and col_8 has no filter. Sorting is enabled via the sort extension.
